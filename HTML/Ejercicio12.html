Conceptos Básicos de la Web

El HTML es la base de todo. Se puede decir que HTML es el lenguaje que usamos para estructurar las páginas.

Como dijo un profesor: "La práctica hace al maestro".

Aquí tienes un ejemplo de cómo se ve una etiqueta sin que el navegador la ejecute: 

<p>Esto es un párrafo</p>

Es muy importante prestar atención a los detalles y tener cuidado con las etiquetas que abrimos y cerramos.
